# 第三章：中文排版示例

这一章主要演示中文排版效果。

## 段落缩进

中文段落默认首行缩进 2 个字符，这样看起来更舒服。这是第一段文字，用来演示首行缩进的效果。你可以看到每一段的开头都自动缩进了。

这是第二段文字，同样有首行缩进。中文排版讲究天头地脚，字间距和行间距也要合适。md2epub 内置的 CSS 样式已经做了基本的优化，确保在电子阅读器上有良好的阅读体验。

## 技术与中文混合

在技术笔记中，经常会出现中文和英文、代码混排的情况。比如我们提到 **TypeScript** 语言，或者提到一个函数名 `generateEpub()`，这些都需要正确处理。

根据需求描述：
> 中文段落首行缩进 2em，英文段落不缩进通过 lang 标签区分。

## 代码示例

```typescript
// 中文注释也没问题
interface Book {
  title: string;       // 书名
  author: string;      // 作者
  chapters: Chapter[]; // 章节列表
}

function createBook(title: string): Book {
  return {
    title,
    author: "未知作者",
    chapters: []
  };
}
```
