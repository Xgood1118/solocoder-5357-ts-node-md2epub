# 第一章：入门指南

欢迎使用 **md2epub**！这是一个将 Markdown 转换为 EPUB 的工具。

## 为什么需要这个工具？

当你有大量 Markdown 笔记时：

- 在电脑上用 VS Code 看很舒服
- 但在 Kindle 等电子阅读器上直接看 Markdown，排版全乱了
- 标题变成正文、代码缩进丢失、图片无法显示

`md2epub` 就是为了解决这个问题而生的。

## 特性一览

1. 完整的 Markdown 语法支持
2. 多级目录导航
3. 图片自动下载和内嵌
4. 中文字体嵌入
5. EPUB 3 标准格式
